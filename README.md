# HR Analytics Dashboard – Power BI

## Project Overview
This project focuses on analysing employee data using Power BI to understand workforce trends, employee demographics and attrition patterns.

The dashboard provides interactive visualisations to help explore HR data and support data-driven decision-making.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- CSV Dataset

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset, sourced from Kaggle.

The dataset contains employee-related information used to analyse attrition, demographics, job roles and satisfaction.

## Dashboard Features
- Total Employees
- Employee Attrition Count and Rate
- Average Age
- Average Monthly Income
- Attrition by Department and Gender
- Attrition by Job Role
- Job Satisfaction Analysis
- Overtime Analysis
- Employee Demographics
- Interactive Filters and Slicers

## Key Objectives
- Analyse employee attrition patterns.
- Understand workforce distribution across departments.
- Explore the relationship between job satisfaction and attrition.
- Identify employee trends based on age, gender and job role.
